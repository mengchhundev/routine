# Product documents

The two source documents belong here:

- `ROUTINE-PROPOSAL.md` — problem, users, features, MVP scope, business model
- `ROUTINE-PROJECT-PLAN.md` — phases, schema, milestones, definition of done

They are the reference for what gets built and in what order. Where the code
makes a decision those documents did not anticipate, the reasoning is recorded
in [../architecture/decisions.md](../architecture/decisions.md) rather than by
quietly editing the plan.
